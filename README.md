# Nyasha & Lee: wedding invitation

Animated wedding invitation for Saturday 6 March 2027, Swan Creeks Garden, Harare.

Static site, no build step. Deploy on Vercel with the framework preset set to "Other" and the root directory left as is.

- `index.html`: the invitation (edit the `INVITE` block in the script to change details; the static fallback section near the top mirrors them)
- `assets/`: images and the song (`song.mp3`)
- `og.jpg`: the link preview image for WhatsApp and social apps
